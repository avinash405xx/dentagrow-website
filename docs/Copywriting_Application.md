# Copywriting Application

The supplied copywriting PDFs emphasize:

1. Headline
2. Subheadline
3. Problem
4. Solution
5. Benefits
6. Features
7. Who it is for
8. Bonuses / offer context
9. Proof
10. CTA / urgency
11. FAQ
12. Final push

For DentaGrow, this structure is adapted to a B2B dental-practice service:

- Lead with the operational outcome, not AI/tool names.
- Make the front-desk workload problem concrete.
- Explain the system in simple steps.
- Show benefits before technical implementation details.
- Treat acquisition as an optional growth layer for clinics that need it.
- Use example dashboard values only when explicitly labelled as examples.
- Never invent testimonials or social proof.
- Use clear, conversational English rather than technical jargon.
